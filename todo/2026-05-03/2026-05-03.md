#  Heizungsanlage Fehler Betriebsart
- [x] determine_mode: Bestehende Erkennung (manchmal nicht richtig)
  → Logik vereinfacht und an Prioritätstabelle angepasst:

  | Prio | Modus | Bedingung |
  |------|-------|-----------|
  | 1 | Desinfektion | dhw.disinfecting == true |
  | 2 | Warmwasser | tapwater_active == true (3-Wege-Ventil auf WW) |
  | 3 | Heizung | heating_active == true |
  | 4 | Standby | alles andere |

  Vorher: dhw.charging, dhw.active, burner_active als separate Checks
  → Timing-Probleme weil dhw.charging/active manchmal verzögert schalten.
  Jetzt: Nur tapwater_active als WW-Indikator (3-Wege-Ventil ist eindeutig).
  heating_active statt burner_active (Brenner kann auch bei WW laufen).
